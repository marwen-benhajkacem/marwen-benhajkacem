## 🎯 Featured projects

### 💧 [Smart Irrigation Agent (Deep Learning + RL)](https://github.com/marwen-benhajkacem/smart-irrigation-dl-rl)
Two-module agent: **soil-moisture forecast from D+1 to D+7** (LSTM, GRU, Transformer) and **daily irrigation decision from 0 to 20 mm** (PPO, DQN) on gym-DSSAT, with an LLM module explaining each decision. Team project with Farah Baaziz.
- **Stack:** PyTorch, Stable-Baselines3, gym-DSSAT, ERA5-Land, SMAP, Docker
- **Status:** 🚧 In progress

### 🪐 [Kepler Exoplanet Classification](https://github.com/marwen-benhajkacem/kepler-exoplanet-classification)
Planets vs false positives on **9,564 NASA objects**. Leakage features removed, imputation and PCA inside the pipeline, **cross-validation grouped by star**. Best model on the held-out test set: Random Forest, **F1 0.88, AUC 0.97**.
- **Stack:** Python, Scikit-learn, Pandas
- **Status:** ✅ Completed

### 🧾 [Invoice Information Extraction (NLP + LLM)](https://github.com/marwen-benhajkacem/invoice-information-extraction-nlp)
Extracts **supplier, date, number, HT and TTC** from PDFs and scans. Rule-based and LLM extractors, OCR, and an **evaluation harness with per-layout error analysis** (a held-out layout test exposed rule overfitting). Evaluated on synthetic invoices; real-invoice benchmark in progress.
- **Stack:** Python, pdfplumber, Tesseract, LLM API, Streamlit
- **Status:** 🚧 In progress

### 🛒 [Sales Data Cleaning & Analysis (R)](https://github.com/marwen-benhajkacem/sales-data-cleaning-r)
Merge and clean two datasets, feature engineering (shipping delay, order score), Top 10 products, 10+ charts.
- **Stack:** R, dplyr, tidyr, data.table, ggplot2
- **Status:** ✅ Completed

### 📈 [Power BI Sales Performance Dashboard](https://github.com/marwen-benhajkacem/power-bi-sales-performance-dashboard)
Interactive report on orders and returns with DAX measures by region and product.
- **Stack:** Power BI, Power Query, DAX
- **Status:** ✅ Completed
